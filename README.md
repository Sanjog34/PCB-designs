# PCB-designs
PCBs i designed


1. Micromouse_Nano: PCB designed for a line-maze-solving micromouse, featuring an Arduino Nano, L293D motor driver, QTR-8 sensor array, and two N20 motors.
2. Camera Setup Device: A compact handheld device designed during my internship at Yarsa Tech to test and verify the functionality of camera modules.
3. CH334F Board: A UART hub PCB based on the CH334F, integrating four CH340 USB-to-UART converters and a USB Type-C interface.
4. Watch_Conn: An ESP32-based smartwatch PCB featuring a display, SD card slot, DAC, and audio amplifier for speaker output.
